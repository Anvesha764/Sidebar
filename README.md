# 📂 Responsive Sidebar Menu (HTML & CSS)

A clean and responsive sidebar navigation menu built using **pure HTML and CSS**.  
This project uses the **checkbox toggle technique** to open and close the sidebar, without any JavaScript.

---

## 🚀 Live Demo
https://anvesha764.github.io/Sidebar/
---

## ✨ Features
- 📱 Responsive sidebar layout
- 🎯 Toggle menu using checkbox hack
- 🎨 Smooth open/close animations
- 🖼 Background image support
- 🔤 Google Fonts (Poppins)
- ⭐ Font Awesome icons
- 💡 No JavaScript used

---

## 🛠 Tech Stack
- HTML5  
- CSS3  
- Font Awesome  
- Google Fonts

## ⚙️ How to Run Locally
1. Clone the repository  
   git clone https://github.com/Anvesha764/sidebar-menu-css.git  

2. Open the project folder  
   cd sidebar-menu-css  

3. Open `index.html` in your browser
